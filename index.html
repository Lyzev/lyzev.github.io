About

Hi, I'm Lyzev ⎡Бен⎤, a software developer from Central Europe. I started programming in 2020 and learned Java as my first programming language.

Projects

  • Schizoid - Elevate your Minecraft gameplay with this free and feature-rich client built with Fabric API and utilizing mixin-based injection techniques.
  • Kratos - A flexible Kotlin library for seamless management and tracking of customizable application settings.
  • PBH - A Minecraft server plugin that improves horse breeding by boosting and balancing speed, jump, and health stats.
  • SchummelPartie - A configurable Pummel Party mod with an in-game GUI and gameplay modules for practice and custom sessions.
  • HorsePower - A Minecraft mod that scores horse stats, displays power in HUD/inventory, and includes commands to find strong horses nearby.
